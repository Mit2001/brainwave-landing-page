# Brainwave Landing Page

A responsive business landing page recreated from a Figma design using HTML, CSS, and Bootstrap 5.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons

## ✨ Features

- Responsive navigation bar
- Hero section
- Services section with Bootstrap cards
- Customer review section
- Our Story section
- Statistics section
- Why Choose Us section
- Case Studies section
- Testimonial section
- Call-to-action section
- Responsive footer
- Mobile-friendly design

## 📱 Responsive Design

The website is responsive and works across:

- Desktop
- Tablet
- Mobile

Bootstrap's responsive grid system and custom CSS were used to create the layouts.

## 🎯 Project Objective

The goal of this project was to convert a Figma design into a responsive website using HTML, CSS, and Bootstrap.

This project helped me practice Bootstrap's grid system, cards, flexbox, responsive layouts, custom CSS, and Figma-to-code implementation.
